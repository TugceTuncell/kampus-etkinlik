# Kampüs Etkinlikleri - Sprint 1 Prototipi

Bu proje, Süleyman Demirel Üniversitesi kampüsünde gerçekleştirilecek olan seminer, atölye ve spor müsabakası gibi etkinliklerin takibini sağlamak amacıyla geliştirilen web uygulamasının ilk sprint teslimidir.

## Teknik Detaylar
Bu sprint aşamasında proje kısıtlarına uygun olarak yalnızca saf HTML5 kullanılmıştır. CSS ve JavaScript dilleri ile veri kaydetme işlemleri projeye dahil edilmemiştir. Sayfalar arası bağlantılar ve form yapıları semantik etiket kurallarına uygun olarak tasarlanmıştır.
